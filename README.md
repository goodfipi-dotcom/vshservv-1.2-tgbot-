# VSH Service — Telegram-бот исполнителей

Принимает заявки, рассылает их подходящим рабочим, выдаёт вход в приложение.

## Запуск

Точка входа: `bot.py` (Python 3.11, long polling).

## Переменные окружения

| Переменная | Зачем | Пример |
|---|---|---|
| `TG_BOT_TOKEN` | Токен бота от @BotFather | `8174571129:AAE...` |
| `OWNER_CHAT_ID` | Telegram-id владельца — ему идут заявки и отчёты | `7693616720` |
| `DATABASE_URL` | База Neon: рабочие, заявки, журнал доставки | `postgresql://...` |
| `MINI_APP_URL` | Адрес приложения исполнителя | `https://mini-appsvsh.vercel.app` |
| `API_BASE` | Тот же адрес — оттуда бот забирает опубликованные заявки | `https://mini-appsvsh.vercel.app` |
| `CLIENT_URL` | Сайт для заказчиков | `https://vsh-web.vercel.app` |

Без `TG_BOT_TOKEN`, `OWNER_CHAT_ID` и `DATABASE_URL` бот не стартует — это намеренно.

## Важно

Бот работает через long polling. **Одновременно можно запускать только один экземпляр** —
второй получит от Telegram ошибку 409 и не будет получать сообщения.
